# Movie Script Generator

A Python-based random movie script generator that creates
formatted screenplay drafts using CSV and text files.

## Features

- Random scene selection
- Random dialogue selection
- CSV-based character data
- Text-file based scenes and dialogue
- Automatic screenplay generation

## How It Works

The program reads character data from CSV and scene/dialogue
data from text files, combines them randomly, and generates
a screenplay.

## Python Concepts Practiced

- Variables
- Lists
- Dictionaries
- Functions
- Loops
- File I/O
- CSV handling
- Random selection
